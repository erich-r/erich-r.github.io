    "## Creating and Using a Python environment with Miniconda\n",
    "\n",
    "Once Miniconda is installed, it is recommended to create a separate Python environment for each project. This keeps the dependencies of different projects isolated and avoids conflicts between Python packages.\n",
    "\n",
    "1. Open **Anaconda Prompt** on Windows, or a **Terminal** on Mac/Linux.\n",
    "\n",
    "2. Create a new environment with Python installed. For example, to create an environment called `sciprog` with Python 3.11:\n",
    "\n",
    "   ```bash\n",
    "   conda create -n sciprog python=3.11\n",
    "   ```\n",
    "\n",
    "3. Activate the environment:\n",
    "\n",
    "   ```bash\n",
    "   conda activate sciprog\n",
    "   ```\n",
    "   **Remember to always activate the environment before working!** \n",
    "\n",
    "   You should now see `(sciprog)` at the beginning of your terminal prompt, indicating that the environment is active.\n",
    "\n",
    "4. You can check that Python is correctly installed by running:\n",
    "\n",
    "   ```bash\n",
    "   python --version\n",
    "   ```\n",
    "\n",
    "5. When you are finished working, you can deactivate the environment with:\n",
    "\n",
    "   ```bash\n",
    "   conda deactivate\n",
    "   ```\n"
   ]
