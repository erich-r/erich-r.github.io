Scientific Programming
=======================

The official website of the Scientific Programming course, part of the Data Science degree programme at the University of Trento, for the 2026/2027 academic year.

Timetable and Lecture rooms
---------------

For the part A lab:

* Tuesdays 16.30 - 18.30, room A201
* Fridays 15.30 - 17.30, room A201

Course Overview
---------------

Topics covered in this course include:

* Datastructures
* Controlflow
* Functions
* Recursion
* Pandas
* Numpy
* OOP

Learning Objectives
-------------------

By the end of the course, students should be able to:

* Develop programs to solve problems
* Analyze and visualize data
* Write clear code
* Apply computational techniques to real-world problems
